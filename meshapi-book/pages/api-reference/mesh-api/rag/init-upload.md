# Init Upload

### Authentication

AuthorizationBearer

Bearer authentication of the form `Bearer <token>`, where token is your auth token.

### Request

This endpoint expects an object.

file_name

mime_type

embed

metadata

### Response

Successful Response

file_id

signed_url

expires_at

### Errors

422

Unprocessable Entity Error
